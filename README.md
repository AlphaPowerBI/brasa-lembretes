# Brasa Lembretes

Aplicação web de lembretes de atividades, em página única (HTML, CSS e JavaScript no mesmo arquivo `index.html`).

Criada com IA generativa para um exercício de testes de software. **Por requisito do exercício, o projeto não possui testes automatizados**: os testes são definidos e executados manualmente pelo grupo.

## Funcionalidades

- Cadastro de lembrete com título, descrição, tipo (único ou recorrente: diário, semanal, mensal) e data/hora futura
- Lista dos lembretes futuros, do mais próximo ao mais distante, agrupada por dia
- Alerta na data/hora marcada, com opção de marcar como visto ou adiar
- Edição, exclusão com confirmação e histórico de concluídos
- Dados salvos no armazenamento do navegador (localStorage)
- Tema escuro com tons de laranja, adaptado para computador e celular

## Como rodar

Abra o arquivo `index.html` em qualquer navegador moderno. Não há build nem dependências.

## Publicação

Hospedado na Vercel como site estático (sem configuração adicional).
